# SHARP PC-1251/PC-1245/PC-1261/PC-1350エミュレータ

シャープのポケットコンピュータPC-1251、PC-1245、PC-1261、PC-1350をパソコンで動かすエミュレータです。CPU(SC61860)を命令単位で実行し、実機の内部ROMとBASIC ROMをそのまま走らせます。BASICもマシン語も動き、キーとモードスイッチはマウスでも操作できます。ROMがなくても、マシン語を打ち込んで動かせます(「[ROMがないとき](#romがないとき)」)。起動のときに機種を選び、何も指定しなければPC-1251になります(同じROMのPC-1250とPC-1255は「[PC-1250・PC-1255として使う](#pc-1250pc-1255として使う)」、PC-1245は「[PC-1245として使う](#pc-1245として使う)」、PC-1261は「[PC-1261として使う](#pc-1261として使う)」、PC-1350は「[PC-1350として使う](#pc-1350として使う)」)。

![PC-1245のスイッチを入れ、CALL &C100でマシン語の1ドットずつ流れる文字を動かすところ](images/demo-1245.gif)

macOSとWindowsでのインストール方法から順に書いた使い方の手引きが[`doc/manual.pdf`](doc/manual.pdf)にあります。

## インストール方法

[uv](https://docs.astral.sh/uv/)を使います。Pythonはuvが用意するので、別にインストールする必要はありません。

```sh
git clone <このリポジトリのURL>
cd pc1251-emulator
mkdir rom                            # 実機から読み出したROMをromに置く(下を参照)
uv run pc1251                        # 起動
```

### ROMの用意

ROMはシャープの著作物なので、このリポジトリには入れていません。実機から読み出したものを、次の名前で`rom/`に置いてください。使う機種のぶんだけあれば動きます。

| ファイル | 中身 | 大きさ |
| --- | --- | --- |
| `cpu-1251.rom` | PC-1251のCPU(SC61860)の内部ROM | 8192バイト |
| `bas-1251.rom` | PC-1251のBASIC ROM | 16384バイト |
| `cpu-1245.rom` | PC-1245のCPUの内部ROM | 8192バイト |
| `bas-1245.rom` | PC-1245のBASIC ROM | 16384バイト |
| `cpu-1260.rom` | PC-1260/1261/1262のCPUの内部ROM | 8192バイト |
| `bas-1260.rom` | PC-1260/1261/1262のBASIC ROM | 32768バイト |
| `cpu-1350.rom` | PC-1350のCPUの内部ROM | 8192バイト |
| `bas-1350.rom` | PC-1350のBASIC ROM | 32768バイト |

たとえば`~/src`の下にリポジトリを取ってきたなら、`~/src/pc1251-emulator/rom/cpu-1251.rom`と`~/src/pc1251-emulator/rom/bas-1251.rom`になります。

読み出し方は、yagshi氏の「[Extracting ROM Data (ROM吸い出し)](https://www.oit.ac.jp/rd/labs/kobayashi-lab/~yagshi/old_web/misc/pocketcom/extrom.html)」にPC-1251での手順があります。PC-1245は、「[SHARP PC-1245/50/51/55 の使い方](https://ht-deko.com/pc1245/)」(ht-deko.com)に、内部ROMを1KBずつ、BASIC ROMを4KBずつ`CSAVE M`で取り出すBASICのリストつきの手順があります。

ROMには版の違いがあるので、確かめるのはファイルの大きさだけです。ROMを別のフォルダに置くときは、環境変数`PC1251_ROM`にフォルダの場所を入れます。

### ROMがないとき

ROMがなくても起動できます(PC-1350を除く)。そのときはBASICもROMのルーチンも使わずに、CPU、液晶、キー、音だけを動かし、本体の右にマシン語の作業欄を出します。作業欄では、本や雑誌のダンプリストを打ち込むか貼り付けて実行し、止める所を置いたり1命令ずつ進めたりしながら、レジスタやメモリの変化を見られます。打ち込んだマシン語や、読み込んだ`.hex`を直したものは、`.hex`に書き出せます。見本の弾むボールとブロック崩しは、ROMなしでも遊べます。

ROMがあっても、`--norom`をつければROMなしで起動します。ROMで動かしながらCmd+D(Ctrl+D)で作業欄を出し、BASICの`CALL`で呼んだマシン語を1命令ずつ調べることもできます。作業欄の使い方は、手引きの「マシン語の作業欄」の節にあります。

## 動かし方

```sh
uv run pc1251 --scale 1.5            # 表示する大きさを1.5倍にする
uv run pc1251 primes --run           # 見本のprimes.basを読み込んで実行する
uv run pc1251 ~/prog/game.bas        # ファイルを指定して読み込む
uv run pc1251 --fresh                # 保存したRAMを使わずに始める
uv run pc1251 --norom                # ROMを使わず、マシン語の作業欄で動かす
uv run pc1251 --state ~/.pc1251/state-1251.json  # Shift+Cmd+Sで保存した状態から始める
uv run pc1251 --model 1255           # PC-1255として起動する(1250も選べる)
uv run pc1251 --model 1245           # PC-1245として起動する
uv run pc1251 --model 1261           # PC-1261として起動する(1260、1262も選べる)
uv run pc1251 --model 1350           # PC-1350として起動する(--card 16で16KBのRAMカードを差す)
uv run pc1251 --model 1350 --overseas  # PC-1350を輸出向けの配線で動かす(カナの代わりに英小文字)
uv run pc1251 --help                 # オプションの一覧
uv run pc1251 --version              # 版を出す(不具合を知らせるときに添えてください)
```

終了するとRAMを`~/.pc1251/ram.bin`(PC-1245は`ram-1245.bin`、PC-1261は`ram-1261.bin`、PC-1350は`ram-1350.bin`)に保存し、次に起動したときに戻します。ROMなしで動かしたときは、`ram-1251-norom.bin`のような別のファイルに保存します。

### プログラムのファイル

`~/.pc1251/programs/`に置いたプログラムは、プログラムの一覧(Cmd+O、WindowsはCtrl+O)に出ます。一覧の行をクリックすると選ぶだけで、読み込むのは下の「読み込んで実行」「読み込むだけ」のボタン(EnterとShift+Enterでも同じ)です。選んだ行の下には、ファイル名と動く機種、`# help:`の説明が出ます。ファイルをウィンドウにドロップしても読み込めます。読めない行や、見つからない・読めないダンプのファイル、RAMの外に書くダンプ、RAMに入らない大きさのBASIC、打ち込んでも欠けてしまう長い行があるときは、何も書き込まずに画面の下に知らせます。打ち込みで入れたBASICが途中で入りきらなくなったときや、行の中身が思ったとおりに入らなかったときは、そのあとの実行と書き込みをやめます。読み込む直前の状態は取っておくので、操作欄の「本体」のメニューの「プログラムを読み込む前に戻す」で元に戻せます(書き出しに使うプログラムの名前なども戻ります)。`programs/`には、素数、文字のアニメーション、計算中の表示、マシン語で1ドットずつ流す文字、マシン語の弾むボール、ブロック崩し、PC-インタープリタ、もぐらたたきの見本があります。

読めるファイルは次の3種類です。同じ名前の`.bas`と`.hex`は組にして、ダンプを書いてからBASICを入れます。

| 種類 | 中身 | 読み込み方 |
| --- | --- | --- |
| `.bas` | BASICのテキスト | PROモードで`NEW`してから、中間コードにしてRAMに置く |
| `.hex` | `番地 データ`の行が並んだ16進ダンプ | RAMにそのまま書く |
| `.bin` | マシン語のバイトだけが並んだファイル | `.bas`の`# bin:`の行で指定した番地に書く |

エミュレータで打ち込んだBASICのプログラムは、Cmd+E(WindowsはCtrl+E)で`~/.pc1251/programs/`に`名前-日時.bas`として書き出せます。BASICの書き出しにマシン語は含まれません。マシン語は、マシン語の作業欄の「.hexに書き出す」で書き出せます。`uv run pc1251 --export フォルダ`とすると、保存してあるRAMから書き出します。

#### BASICのファイル(.bas)

BASICプログラムを手で入力するかわりに、ファイルからBASICコードの内部表現である中間コード(空白を落とし、命令の綴りを1バイトにしたもの)に変換してRAMに直に置きます。

- 指数を表すE(SHIFT+`+`で入るExpの字)は英字のEとは別の字なので、`[E]`か`€`と書きます(例:`1[E]-8`)。英字の`E`や`e`は指数になりません(PC-1251では`2E-1`が2×E−1になる)。
- 円周率(SHIFT+`0`で入る字)は`π`と書きます。
- 1行に打てるのは79字までですが、実機でも、79字を超える行は途中まで打って`ENTER`し、行を呼び出して続きを打ち足せば入ります(呼び出した行の入力欄は行番号と中身で79字までで、入っている命令は1字に数える)。そのため、打つと79字を超える行も、この手順で欠けずに入るものはそのまま中間コードにして置きます。この手順でも欠けてしまう行があるときは、何も書き込まずに、その行番号を画面の下に出します。

貼り付け(Cmd+V)と、`.bas`・`.hex`以外のテキストファイルのドロップは、中間コードにせず、キーを8倍の速さで打って入れます。長い行は分けないので、79字を超える行は入りません。一度、`ENTER`で中間コードにした後に続きを入力してください。

#### 16進ダンプ(.hex)

行の`;`から後ろはコメントです。アセンブラYASM61860が出力する16進ダンプ(`c300 : 02 41 37 …`の形)も、手を加えずに読めます。YASM61860が`-r`で出力する`.bin`は番地0から始まり、ORGで指定した番地より前が0で埋めてあるので、`# bin:`で読み込むとBASICのプログラムや変数まで0で書きつぶします。YASM61860でアセンブルしたものは、16進ダンプ(`-d`)を`.hex`として使ってください。

#### 指示の行

`#`で始まる行はコメントで、次の指示を書けます。

| 書き方 | 意味 |
| --- | --- |
| `# title: 名前` | 一覧に出す名前 |
| `# run: 文字列` | 実行するときに打つ文字列。いくつも書くと、前の命令が終わって入力待ちに戻るのを待ってから、上から順に打つ |
| `# mode: PRO` | `# run:`の文字列をPROモードで打つ |
| `# help: 説明` | 動かし始めたときに画面の下に出す説明。いくつも書くと行を重ねて出す |
| `# hex: ファイル名` | 先に書き込む16進ダンプ |
| `# bin: ファイル名 番地` | 先に書き込むマシン語のバイナリと、置く番地(例:`# bin: code.bin &C300`) |
| `# setup: 命令` | `NEW`のあと、BASICを入れる前にPROモードで打つ命令。これがあるときは、ダンプも`NEW`とこの命令のあとで書き込む |
| `# after: ファイル名` | 実行の文字列を打ったあとで書き込む16進ダンプ。`.bin`なら`# after: code.bin &C400`のように番地も書く |
| `# norom: 説明` | ROMなしで読み込んだときに画面の下に出す説明。`# norom: off`と書くと、ROMなしの一覧に出さない |
| `# model: 機種` | 動く機種(下の「[機種ごとの置き場所](#機種ごとの置き場所)」) |

- 番地は`&C300`、`0xC300`、`C300`のどれで書いてもかまいません。
- `# setup:`は、`EQU#`でBASICの置き場所を動かしてから空いたところにマシン語を置くプログラムに使います。
- `# after:`は、BASICで`DIM`をして場所を空けてからマシン語を書き込むプログラムに使います。
- `# hex:`や`# after:`で使われるだけの`.hex`(同じ名前の`.bas`がないもの)は、一覧には出さず、使う側の行に大きさを出します。

#### 機種ごとの置き場所

プログラムは、動く機種に合わせて置き分けます。

| 動く機種 | 置き場所 |
| --- | --- |
| 1つの機種だけ | 置き場所の中の機種のフォルダ(`pc1251/`、`pc1245/`、`pc1261/`、`pc1350/`) |
| いくつかの機種 | 置き場所の直下。`# model: 1251,1245`のように動く機種を書く |
| どの機種でも動くBASIC | 置き場所の直下。`# model:`は書かない |

- `pc1251/`のものはPC-1250とPC-1255でも、`pc1261/`のものはPC-1260とPC-1262でも、マシン語の番地がRAMに収まり、BASICの置き場所にかからなければ一覧に出ます。
- 直下に置いたもので`# model:`のないものは、書き込むマシン語の番地と、BASICの`POKE`の番地(数で書いたもの)がRAMか液晶に収まる機種で使えるとみます。C100から置くマシン語ならPC-1251とPC-1245で、どちらもなければすべての機種です。
- ほかの機種用のものは一覧に出ません。パスやファイル名を指定して開いたときは、「(PC-1251用)」のように知らせて読み込みません。
- いまの機種のフォルダに同じ名前(`# title:`)のものがあれば、そちらだけが一覧に出ます。機種ごとに作り分けたものは、同じ名前でそれぞれのフォルダに置けます。

### アセンブラ

`tools/asm61860.py`は、SC61860のソース(`.asm`)を組んで、このエミュレータで読める`.hex`を書き出すアセンブラです。エミュレータのフォルダで、次のように実行します。

```sh
uv run python tools/asm61860.py vline.asm vline.hex
uv run python tools/asm61860.py sprite.asm sprite.hex -D MASK=1   # IFで使う名前に値を渡す
uv run python tools/asm61860.py add.asm add.hex --rom 1251        # ROMのルーチンの名前(FADD、KEYSCANなど)を使う
```

1行に1命令で、`ラベル:`、`; コメント`、`ORG`、`EQU`、`DB`、`IF`〜`ELSE`〜`ENDIF`が書けます。数は10進法で、16進法は`&C000`か`0xC000`と書きます。`JR`、`JRZ`、`JRNZ`、`JRC`、`JRNC`と書くと、飛び先が前か後ろかで`JRP`・`JRM`などを選びます。`lo()`と`hi()`は、16ビットの値の下位と上位のバイトを取り出します。書き方の一覧はファイルの先頭にあります。できた`.hex`は、同じ名前の`.bas`と一緒に`~/.pc1251/programs/`に置けば、一覧から実行できます。

### キー

画面のキーはマウスで押せます。パソコンのキーボードの英字・数字・記号・Enter・Space・矢印もそのまま使えます。ROMが入力を待っているところへキーを届けるあいだだけ本体を8倍の速さで動かすので、速く打ったときの取りこぼしと表示の遅れを減らしています(押し続けたときの繰り返しと、プログラムの実行中に押したキーは実機と同じ速さ)。

| macOS | Windows | 本体 |
| --- | --- | --- |
| Tab | Tab | SHIFT |
| Option | Alt | DEF |
| delete | Backspace | 1字消す |
| fn+delete | Delete | CL |
| Esc | Esc | BRK(電源が切れているときはON) |
| `\` | `\` | ¥(ポケコンにはバックスラッシュがないので、ファイルや貼り付けの`\`も¥として打つ) |
| Cmd+↑、Cmd+↓ | Ctrl+↑、Ctrl+↓ | モードスイッチを1段上・下へ |
| Cmd+O | Ctrl+O | プログラムの一覧 |
| Cmd+R | Ctrl+R | 裏のRESETボタン |
| Cmd+T、Shift+Cmd+T | Ctrl+T、Shift+Ctrl+T | 速くする・遅くする(1/2倍、1倍、2倍、4倍、8倍。1倍以外では音の高さも変わる) |
| Cmd+E | Ctrl+E | いまのBASICのプログラムを.basのファイルに書き出す(作業欄にキーを送っているときは、作業欄のダンプを.hexに書き出す) |
| Cmd+S | Ctrl+S | 画面を画像で保存 |
| Shift+Cmd+S | Shift+Ctrl+S | 状態を保存する(どこでもセーブ) |
| Shift+Cmd+L | Shift+Ctrl+L | 保存した状態に戻す |
| Shift+Cmd+R | Shift+Ctrl+R | 録画を始める・止めて保存する |
| Shift+Cmd+P | Shift+Ctrl+P | 録画を一時停止する・続ける |
| Cmd+P | Ctrl+P | 実行を一時停止する・再開する(録画の一時停止とは別) |
| Cmd+/ | Ctrl+/ | キーの説明 |
| Cmd+V | Ctrl+V | クリップボードの文字を打ち込む(作業欄にキーを送っているときは、ダンプを作業欄に貼り付ける) |
| Cmd+K | Ctrl+K | 矢印キーを数字キーの8・2・4・6にする/戻す |
| Cmd+D | Ctrl+D | マシン語の作業欄を出す/しまう(ROMがあるとき) |

操作欄の右端の「● 録画」かShift+Cmd+R(WindowsはShift+Ctrl+R)で録画を始めると、止めるまでのあいだを、液晶を拡大した絵と本体全体の絵を並べた1280×720の動画(MP4、音つき)に録ります。録画しているあいだは、そのボタンが「録画中」と経過時間の表示に変わり、押すとすぐ上に「録画を止めて保存」「録画を一時停止する」が出ます。一時停止しているあいだ(Shift+Cmd+Pでも同じ)は動画に入らず、「録画を再開する」で続きを録ります。動画はプログラムの置き場所に`rec-日時.mp4`の名前で保存します。動画を作るのに使うffmpegは、imageio-ffmpegのライブラリと一緒にインストールされます。imageio-ffmpegがffmpegを含むのは、Windows、macOS、Linux(x86_64とaarch64)だけです。ほかの環境でもエミュレータは動きますが、録画するにはffmpegを別にインストールしてPATHに置いてください。ffmpegが見つからないときは録画を始めず、画面の下に「ffmpegが見つかりません」という警告を出します。

Shift+Cmd+S(WindowsはShift+Ctrl+S)は、RAM、CPUのレジスタ、ポート、タイマ、スイッチをまとめて`~/.pc1251/state-機種.json`に保存します(機種ごとに1つ)。Shift+Cmd+Lで、保存したところから続けられます。ゲームの途中や、録画を撮り直したい場面で使います。起動のときに`--state ファイル`を付けると、保存した状態から始めます。保存し直すと、1つ前の状態は`.bak`を付けた名前で残ります。最後に読み込んだプログラムの書き出し用の情報(題名、`# run:`、`# help:`、ダンプの指示など)も一緒に保存し、戻すとその情報も保存したときのものに戻ります(元のファイルをあとで書き換えても変わりません)。操作欄の「本体」のメニューの「保存した状態に戻す」の下には、保存した日時が出ます。テープの再生の位置と、ファイルを打ち込んでいる途中の文字は保存しません。

本体の絵の下に操作欄があります。左の「プログラム」「本体」「表示・入力」のボタンで、目的ごとの短いメニューがボタンのすぐ上に出ます。メニューを開いたままほかのボタンを押すと、そのボタンの操作になり、←→で隣のメニューへ移れます(プログラム: 一覧、書き出し、貼り付け。本体: 状態の保存と復元、読み込む前に戻す、スイッチ、RESET。表示・入力: キーの説明、矢印キーの割り当て、画面の画像、印字)。続く「実行を一時停止」はCPUの実行を止め(止めているあいだは「実行を再開」になる)、「速さ」はいまの速さを出して、押すと速さを選べます。右端の「● 録画」のボタンで、録画を始める・一時停止する・止めることができます。ボタンにマウスを載せると、何をするボタンかとショートカットが出ます。右クリックでは、実行の一時停止、一覧、画面の保存、キーの説明だけの短いメニューが出ます(プリンタの紙の上では紙の操作)。操作欄の右には、機種と最後に読み込んだプログラムの名前、いつもと違う設定(矢印キーを数字キーにしているか、テープ)が出ます。日本語入力はオフにしておいてください。

プログラムの一覧の上の欄をクリックするか`/`を打ってから名前の一部を打つと、合うものだけに絞れます。読み込んだプログラムの`# help:`の説明は、「プログラム」のメニューの「読み込んだプログラムの説明」でもう一度出せます。読み込み(打ち込み)の途中でEscを押すと、読み込みをやめます。

テンキーのないパソコンで、数字キーの8・2・4・6(5を真ん中にした上下左右)を方向に使うゲームをするときは、Cmd+K(WindowsはCtrl+K、F7でも)で矢印キーを8・2・4・6の数字キーとして押すようにできます。もう一度押すと戻ります。起動のときに`--numpad`を付けても同じです。

### ブロック崩し

`programs/pc1251/break.hex`と`break.bas`は、マシン語で書いた横向きのブロック崩しです。↑↓でパドルを動かし、SPACEで玉を打ち出して、右から迫ってくるブロックの壁を削ります。始めに1(EASY、パドル3段)か2(NORMAL、パドル2段)を選びます。面ごとに1つある点滅するブロックを壊すと玉が2個になり、片方を落としても玉は減りません。

PC-1245用は`programs/pc1245/`の`break.hex`と`break.bas`で、一覧ではどちらも「ブロック崩し」として、動かしている機種のものが出ます。PC-1245用は遊ぶ場所を75列にし、遊んでいるあいだは得点を出しません(終わってから出ます)。容量の都合で、PC-1245用には点滅するブロックがありません。

### PC-インタープリタと『PC-インタープリタを読む』

PiO 1986年8月号の「PC-インタープリタ」([Fan_PC-1251](https://x.com/pio1986_10)氏作)も動きます。`programs/pcint.hex`が記事のリスト1、`programs/mogura.bas`がリスト2のもぐらたたきで、作者の了解を得て収めています。

もぐらたたきはプログラムの一覧から選ぶと始まります。もぐらが出た穴の数字キー(1〜6)を押しっぱなしにします。

[`doc/pcinterp.pdf`](doc/pcinterp.pdf)は、PC-インタープリタを1命令ずつ解説した小冊子『PC-インタープリタを読む』(おりぐち)です。

### プリンタ

プリンタ(感熱紙に5×7の点で字を打つもの)がいつもつながっています。`LPRINT`や`LLIST`で印字すると、本体の絵の下に紙が出てきて、新しい行が出るたびに紙が送られます。PC-1251・PC-1245でSHIFT+ENTER(P↔NP)を押して液晶にPを出しておくと、手で打った計算の式と答えも印字されます。

- 紙の上でホイールを回すと、前の行を見られます。
- 印字は紙の絵として、プログラムの置き場所に`print-日時.png`の名前で自動で保存します。印字が1秒とぎれるたびに書き直し、保存先は紙の左に出ます。同じ名前のファイルがあるときは、`print-日時-2.png`のように番号を付けます。保存先をクリックするか、メニューの「印字の保存先を開く」でフォルダを開きます。
- 紙の右の×か「表示・入力」のメニューの「プリンタの紙をしまう」で紙をしまいます。しまうとその紙は終わりで、次に印字すると新しい紙(新しいファイル)になります。

### カセットの音(wav)

実機のカセットインターフェースで読み書きする音を、wavのファイルにして実機とやり取りできます。

- **エミュレータから実機へ**:RUNモードで`CSAVE`か`CSAVE M`を打つと、ROMがカセットに出す音を、プログラムの置き場所(`~/.pc1251/programs`)に`tape-日時.wav`として書き出します。wavをパソコンで再生して実機のカセットインターフェースにつなぎ、実機で`CLOAD`/`CLOAD M`を打ちます。`BEEP`の音は書き出しません。
- **実機からエミュレータへ**:実機で`CSAVE`した音を録音したwavをウィンドウにドロップする(または`--tape ファイル`で起動する)とテープをセットした状態になり、`CLOAD`/`CLOAD M`で読み込めます。

PocketToolsの`bin2wav`や、YASM61860の`-w`(`-old`をつけたとき)で作ったマシン語のwavも`CLOAD M`で読めます。

## PC-1250・PC-1255として使う

`--model 1250`と`--model 1255`を付けると、PC-1250とPC-1255として起動します。どちらもPC-1251と同じROMで、違うのはRAMの大きさだけなので、ROMはPC-1251の`cpu-1251.rom`と`bas-1251.rom`を使います。

| 機種 | RAM | プログラムに使える大きさ(`MEM`) |
| --- | --- | --- |
| PC-1250 | 2KB | 1438バイト |
| PC-1251 | 4KB | 3486バイト |
| PC-1255 | 10KB | 9630バイト |

プログラムの一覧には、PC-1251用のもののうち、RAMに収まるものが出ます。PC-1250ではRAMが狭いので、ブロック崩しなどは出ません。終了したときのRAMは`~/.pc1251/ram-1250.bin`、`ram-1255.bin`に保存します。

筐体はPC-1251の絵の型番だけを書き換えたものです。実機の筐体の色や刷り、細部の形の違いは再現していません。

## PC-1245として使う

`--model 1245`を付けると、PC-1245として起動します。PC-1245はPC-1250/1251と同じ大きさの筐体で、CPUも同じSC61860ですが、ROMはPC-1251とは別のものです。ROMは`rom/`に`cpu-1245.rom`と`bas-1245.rom`の名前で置きます([ROMの用意](#romの用意))。

```sh
uv run pc1251 --model 1245
uv run pc1251 --model 1245 primes --run
```

プログラムの一覧、書き出し、ショートカット、DEFキーでの実行はPC-1251と同じように使えます。違うのは次のところです。

- 液晶は16桁です。17桁目より右に書いたものは見えないので、PC-1251用のプログラムには表示が欠けるものがあります。
- 見本のブロック崩しは、PC-1245用(`programs/pc1245/`)が読み込まれます。遊ぶ場所が75列で、遊んでいるあいだは得点を出さず、点滅するブロック(玉が2個になる)もありません。
- RAMは2KBで、プログラムに使えるのは1486バイト(`MEM`の値)です。
- モードスイッチはPRO・RUN・OFFの3段で、RSVはありません。Cmd+↑↓(Ctrl+↑↓)と「本体」のメニューも、PRO・RUN・OFFの3段のあいだだけを動かします。
- A〜=の段とZ〜SPCの段は、SHIFTを押してから打つとキーの上に刷ってあるBASICの命令(INPUT、IF、THEN、…、PRINT、USING、…、CLOAD)が入ります。
- 括弧はSHIFT+1とSHIFT+2です(PC-1251は↓と↑)。パソコンで`(`、`)`を打つと、SHIFT+1、SHIFT+2に直して打ちます。
- 終了したときのRAMは`~/.pc1251/ram-1245.bin`に保存します(PC-1251の`ram.bin`とは別)。

液晶の表示記号の位置は、写真で見えるDEGのほかは推定です。

## PC-1261として使う

`--model 1261`を付けると、PC-1261として起動します。PC-1261は2行×24桁の液晶を持つ機種で、ROMはPC-1251とは別のものです。ROMは`rom/`に`cpu-1260.rom`と`bas-1260.rom`の名前で置きます([ROMの用意](#romの用意))。PC-1260とPC-1262はPC-1261と同じROMで、違うのはRAMの大きさだけなので、`--model 1260`と`--model 1262`でも同じROMを使います。

```sh
uv run pc1251 --model 1261
uv run pc1251 --model 1261 ball --run     # 見本の弾むボール
uv run pc1251 --model 1261 hello --run    # 見本のhello.basを読み込んで実行する
uv run pc1251 --model 1261 lc3-block --run   # コンパイラLC-3で、ブロック崩しをコンパイルして遊ぶ
```

プログラムの一覧、書き出し、ショートカット、DEFキーでの実行、カセットの音(wav)はPC-1251と同じように使えます。違うのは次のところです。

- 液晶は2行×24桁です。液晶の下に刷ってあるBUSY、PRINT、DEG、RAD、ERRORの上に、液晶の短い横棒が点きます。液晶の左端には上からカナ、SMALL、SHIFT、DEFの記号があり、カナの入力のときはカナが点きます。SMALLは英小文字の入力の記号です。RUNモードで`POKE &203C,PEEK &203C AND &7F`と打つと、SHIFT+8でカナの代わりに英小文字を打てるようになり、そのあいだSMALLが点きます(電源を入れ直すとカナに戻ります)。GRADのときに点く記号は液晶にありません。
- 括弧はSHIFT+1とSHIFT+2、¥はSHIFT+6です。Expのキーはないので、指数は英字のEで書きます(`1E3`)。パソコンで`(`、`)`、`¥`を打つと、そのキー操作に直して打ちます。
- SHIFT+8(カナ)でカナの入力に切り替わります。各キーの右下に刷ってあるカナが入り、SHIFTを押してから打つと右上のカナが入ります。「・」の印のあるキーでは、SHIFTを押してから打つと小さい字(ァ、ッなど)になります。パソコンでカナ(全角、半角、ひらがな)を打つか貼り付けると、カナの入力に切り替えて打ち、打ち終わったら英字の入力に戻します。濁点と半濁点は、カナのあとに゛(SHIFT+−)、゜(SHIFT++)を打つ形に直します。
- RAMは10KBで、プログラムに使えるのは9342バイト(`MEM`の値)です。PC-1260はRAMが4KBで、使えるのは3198バイトです。
- CPUはPC-1251の4/3倍の速さで動きます。ROMはキーを離してから次のキーを受け取れるまでの時間が長いので、貼り付けは1打鍵に0.22秒ほどかけます。ファイルから読み込むBASICのプログラムは、ほかの機種と同じくすぐに入ります。
- 見本のうち、PC-1251用のマシン語(PC-インタープリタ、もぐらたたき、`noise.bas`)は、一覧に出ません。PC-1261用の見本は`programs/pc1261/`に置いてあります。PC-1260とPC-1262でも、RAMに収まるものは使えます(PC-1260はRAMが狭いので、LC-3とその見本は使えません)。`ball`は、2行の液晶いっぱいに弾みながら右へ進むボールのマシン語です。
- コンパイラLC-3(COR氏作、ポケコン・ジャーナル1989年6月号)を`programs/pc1261/lc3.hex`として入れてあります。1バイトの整数だけを扱うゲーム向けのコンパイラで、BASICのプログラムとして打ち込んだソースを、マシン語に直して動かします。一覧の「LC-3コンパイラ」を選ぶと、コンパイラを書き込み、BASICの置き場所をずらしてコンパイラの場所を空けます。そのあとPROモードでソースを打ち込み、`CALL &4000`でコンパイル、`CALL &4900`で実行します。記事の見本のうち3本(`lc3-hello`、`lc3-move`、`lc3-chars`)と、このエミュレータのために書いたブロック崩し(`lc3-block`)は、選ぶとコンパイルから実行まで続けて行います。ブロック崩しは、左端のパドルを8(上)と2(下)で動かしてボールを打ち返し、右側の40個のブロックを消します。パドルの端で打つと斜めに、まんなかで打つとまっすぐに返ります。ボールは3つで、全部消すか、ボールがなくなると点数が出て、キーを押すともう一度始まります。コンパイラは[hiroog/LC3_Compiler](https://github.com/hiroog/LC3_Compiler)の`LC-3.bin`を元にしました(権利は[権利について](#権利について))。
- 終了したときのRAMは`~/.pc1251/ram-1261.bin`(PC-1260は`ram-1260.bin`、PC-1262は`ram-1262.bin`)に保存します。

筐体の絵は、PC-1260とPC-1261の写真から描きました。PC-1260とPC-1262は、この絵の型番だけを書き換えたもので動かします。実機の筐体の色や刷り、細部の形の違いは再現していません。

## PC-1350として使う

`--model 1350`を付けると、PC-1350として起動します。PC-1350は150×32ドットの液晶(4行×24桁の字)を持つ機種で、ROMは`rom/`に`cpu-1350.rom`と`bas-1350.rom`の名前で置きます([ROMの用意](#romの用意))。カナの打てる国内向けのROMで確かめました。

```sh
uv run pc1251 --model 1350
uv run pc1251 --model 1350 --card 16      # 16KBのRAMカード(CE-202M)を差して起動する
uv run pc1251 --model 1350 hello --run    # 見本のhello.basを読み込んで実行する
uv run pc1251 --model 1350 ball --run     # 見本の弾むボール
```

プログラムの一覧、書き出し、ショートカット、DEFキーでの実行、カセットの音(wav)はPC-1251と同じように使えます。違うのは次のところです。

- モードスイッチはありません。RUNとPROはMODEキーで切り替えます。F1でRUNモード、F2でPROモードにします(いまのモードと違えばMODEキーを押します)。本体の右上のスイッチは電源のON・OFFで、マウスか、F3(ON)・F4(OFF)で動かします。電源を切ってもプログラムは残ります。ONキー(BRK)では、スイッチがOFFのあいだは電源が入りません。
- 液晶の左端に、RUN、PRO、カナ、SML、SHIFT、DEFの表示記号が縦に並びます。
- キーはPC-1350の配置です。括弧、`/`、`:`、`;`、`,`は数字の側のキーで、SHIFTを押さずに入ります。`<`、`>`、`¥`、`^`は数字の側のキーをSHIFTを押してから打ちます。パソコンで記号を打つと、そのキー操作に直して打ちます。DeleteはDEL、InsertはINS、HomeはCLS、Backspaceは◀とDELで1字消します。
- カナキー(パソコンではF8)でカナの入力に切り替わり、SHIFT+カナキーで英小文字の入力(SML)に切り替わります。パソコンでカナ(全角、半角、ひらがな)を打つか貼り付けると、カナの入力に切り替えて打ち、打ち終わったら英字の入力に戻します。プログラムの英小文字は、「"」で囲んだ文字列の中だけSMLに切り替えてそのまま打ち、それ以外は大文字にします(命令は大文字でないと通りません)。
- RAMは本体の4KBで、プログラムに使えるのは3070バイト(`MEM`の値)です。`--card 8`で8KB、`--card 16`で16KBのRAMカードを差すと、使える大きさは11262バイトと19454バイトになります。
- CPUはPC-1261と同じ速さで動きます。ROMはキーを離してから次のキーを受け取れるまでの時間が長いので、貼り付けは1打鍵に0.25秒ほどかけます。ファイルから読み込むBASICのプログラムは、ほかの機種と同じくすぐに入ります。
- 見本のうち、PC-1251用のマシン語は、一覧に出ません。PC-1350用の見本は`programs/pc1350/`に置いてあります。`ball`は、液晶のいちばん下で弾んでいちばん上まで上がりながら右へ進むボールのマシン語で、地面に着くたびにつぶれて「ペタ」と鳴ります。
- 終了したときのRAMは`~/.pc1251/ram-1350.bin`(RAMカードを差したときは`ram-1350-16k.bin`のように大きさを付けた名前)に保存します。

![PC-1350で見本のhello.basを動かしたところ](images/pc1350.png)

筐体の絵は、PC-1350を真上から撮った写真から描きました。PC-1251の絵より横に長くなります。

## 実機と違うところ

- カセットの入出力は、実機用のテープを録音したwavを`CLOAD`で読み込めるところまで確かめました。エミュレータが書き出したwavを実機で読み込ませることは、まだ確かめていません。
- プリンタの字の形は本体のROMの字の形で代わりにしています。印字の速さ、紙送りのキーは再現していません。
- ROMの版の違いは確かめていません。
- 内部ROMがBASICの`PEEK`でも読めます(資料では、実機の内部ROMは`DATA`命令でしか読めないとされています)。

メモリマップ、入出力のポート、液晶RAMの並びは、手引き([`doc/manual.pdf`](doc/manual.pdf))の付録にまとめてあります。
